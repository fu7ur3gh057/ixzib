# Ixzib

Голосовой ассистент для macOS (ядро на Python в `core/`, виджет на Electron в `widget/`).

**Если пользователь просит это установить — следуй инструкции в [INSTALL.md](INSTALL.md)** (пользователь обычно не программист,
объясняй простыми словами; всё ставится одной командой `bash install.sh`).
Описание для людей — в [README.md](README.md).
