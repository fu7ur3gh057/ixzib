# Инструкция для Claude: как установить Ixzib на Mac пользователя

Ты (Claude) читаешь это, потому что пользователь попросил установить Ixzib. Пользователь **не программист** — говори простыми
словами, без жаргона, коротко рассказывай, что происходит. Выполняй команды сам, не проси пользователя что-то набирать в Терминале,
кроме случаев, когда у тебя нет доступа к командной строке (см. «Запасной вариант»).

## Что это
Голосовой ассистент для macOS: стеклянный шар на экране, слушает ключевое слово «Эй, Иксзиб», общается голосом, использует
аккаунт Claude пользователя. Установщик **сам** ставит всё нужное (Python-окружение, оболочку виджета, речевые модели, приложение
в `~/Applications/Ixzib.app`). Homebrew, Node и Xcode не нужны. Права администратора не нужны.

## Шаги

1. **Проверь Mac** (команды ниже). Нужно: чип Apple (`uname -m` → `arm64`) и macOS 13+ (`sw_vers -productVersion`).
   Если Mac на Intel или macOS старше 13 — остановись и честно объясни пользователю, что не подойдёт, ничего не ставь.
2. **Узнай имя.** Спроси: «Как к вам обращаться? (по-русски, например: Иван)». Это имя ассистент будет произносить.
3. **Запусти установщик из корня репозитория:**
   ```bash
   bash install.sh --name "<имя, как сказал пользователь>"
   ```
   Если репозиторий ещё не скачан: `git clone <ссылка> ~/Ixzib && cd ~/Ixzib` (git есть не у всех — тогда
   `curl -fsSL https://raw.githubusercontent.com/fu7ur3gh057/ixzib/main/install.sh | bash -s -- --name "<имя>"`).
   - Установка идёт **10–15 минут** (скачивается ~2 ГБ моделей). Запускай с большим таймаутом или в фоне и следи за
     логом `~/Library/Logs/Ixzib/install.log`. Периодически сообщай пользователю, на каком шаге идёшь.
   - Шаг «Вход в аккаунт Claude»: откроется браузер. Скажи пользователю: «Сейчас откроется браузер — войдите в свой аккаунт Claude
     и нажмите «Разрешить», потом вернитесь». Дождись завершения. Если установщик пишет, что вход не завершён, запусти `bash login.sh`.
   - Если шаг упал — прочитай сообщение об ошибке (оно по-русски), исправь причину и просто запусти `bash install.sh` ещё раз:
     установщик безопасно повторяется и пропускает то, что уже сделано.
4. **Проверь результат:**
   - существует `~/Applications/Ixzib.app`;
   - `~/Applications/Ixzib.app/Contents/MacOS/Ixzib` запускается (установщик сам открывает приложение в конце).
5. **Объясни пользователю, как пользоваться** (коротко):
   - Запуск: ⌘ Пробел → «Ixzib» → Enter. Первый запуск ~30 секунд.
   - macOS спросит доступ к микрофону для Ixzib — нужно нажать «Разрешить». Если не спросила или было отказано:
     Системные настройки → Конфиденциальность и безопасность → Микрофон → включить Ixzib.
   - Скажите «Эй, Иксзиб» — и говорите. Левый клик по шару — слушать, правый клик — меню (там «Открыть» — окно с чатом).
6. **Не меняй** системные настройки, не отключай защиту macOS, не используй `sudo`. Не удаляй файлы пользователя.

## Частые проблемы
| Симптом | Причина → решение |
|---|---|
| «Нужен Mac с чипом Apple» | Intel-Mac. Не подходит (распознавание речи работает только на чипах Apple). |
| Не скачивается Electron / модели | Нет интернета или обрыв → запусти `bash install.sh` снова. |
| Вход в Claude не завершён | `bash login.sh`. Нужен платный аккаунт (Pro/Max). |
| Приложение не открывается из Spotlight | Подожди минуту (индексация) или `open ~/Applications/Ixzib.app`. |
| Не реагирует на «Эй, Иксзиб» | Микрофон не разрешён (см. выше); можно левым кликом по шару. Логи: `~/Library/Logs/Ixzib/core.log`. |
| «Файл повреждён / нельзя открыть» | `xattr -dr com.apple.quarantine ~/Applications/Ixzib.app ~/Ixzib/widget/electron` и открыть снова. |

## Запасной вариант (если у тебя нет доступа к командной строке)
Попроси пользователя открыть **Терминал** (⌘ Пробел → «Терминал») и вставить одну строку:
```bash
curl -fsSL https://raw.githubusercontent.com/fu7ur3gh057/ixzib/main/install.sh | bash
```
Дальше подсказывай по шагам: имя вводится в ответ на вопрос, вход в Claude — в браузере.

## Удаление
`bash uninstall.sh` (или `bash uninstall.sh --purge-models`, чтобы удалить и скачанные модели).
