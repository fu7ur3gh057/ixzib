# Ixzib — голосовой ассистент для Mac

Говорите с Claude голосом: скажите **«Эй, Иксзиб»** — и он слушает, отвечает вслух и выполняет просьбы на вашем Маке
(открыть сайт, включить трек на YouTube, найти файл, написать код…). Внешний вид — маленький стеклянный шар на экране.
Всё распознавание речи и озвучка идут **на вашем компьютере**; в Claude уходит только текст.

## Что нужно
- Mac с чипом Apple (M1, M2, M3, M4…) и macOS 13 или новее
- Подписка Claude (Pro или Max) — та же, что в приложении Claude
- Интернет, ~6 ГБ свободного места, микрофон
- Программировать **не нужно**

## Установка

### Вариант 1 — через приложение Claude (проще всего)
1. Откройте приложение **Claude** на Маке и начните новый чат (лучше во вкладке с кодом/«Code», если она есть).
2. Отправьте сообщение:

   > Установи мне Ixzib по этой ссылке: https://github.com/fu7ur3gh057/ixzib
   > Прочитай файл INSTALL.md в репозитории и выполни установку за меня. Объясняй простыми словами, что делаешь.

3. Claude всё сделает сам. Он спросит, как к вам обращаться, и один раз попросит войти в аккаунт Claude в браузере.
   Установка занимает 10–15 минут (в основном скачивание моделей).

### Вариант 2 — одной командой в Терминале
Откройте **Терминал** (⌘ Пробел → «Терминал») и вставьте:

```bash
curl -fsSL https://raw.githubusercontent.com/fu7ur3gh057/ixzib/main/install.sh | bash
```

## Как пользоваться
- Запуск: **⌘ Пробел → Ixzib → Enter**. При первом запуске разрешите доступ к микрофону.
- Скажите **«Эй, Иксзиб»** — он ответит «Слушаю» и дальше слушает сам, пока вы не скажете «пока» или не замолчите.
- Можно сразу с просьбой: «Эй, Иксзиб, включи Bohemian Rhapsody».
- **Левый клик** по шару — слушать · **правый клик** — меню («Открыть» — окно с чатом и историей, «Закрыть») · **✕** при наведении — выйти.
- Перебить его, пока он говорит: клик по шару или ⌥⇧Пробел.
- Опасные действия (удаление файлов, `sudo` и т. п.) он делает только после вашего «Разрешить».

## Настройки
Файл `~/.ixzib/config.json`:
```json
{ "name": "Иван", "workdir": "~", "safe_root": "~" }
```
`name` — как к вам обращаться, `workdir` — рабочая папка ассистента, `safe_root` — где он может менять файлы без вопросов.

## Если что-то не так
| Проблема | Что делать |
|---|---|
| Не слышит «Эй, Иксзиб» | Проверьте доступ к микрофону: Системные настройки → Конфиденциальность → Микрофон → Ixzib. Левый клик по шару всегда включает прослушивание. |
| Нет ответов / ошибка входа | Запустите `bash login.sh` в папке проекта, чтобы заново войти в Claude. |
| Нет звука | Проверьте громкость и устройство вывода. |
| Логи | `~/Library/Logs/Ixzib/` |

Удаление: `bash uninstall.sh` (с ключом `--purge-models` удалит и скачанные модели).
